# v0.1.4 — Complete Core Profile

Dieser Entwicklungsmeilenstein ergänzt den kompatiblen Life-Path-Kern um
Geburtstags-, Einstellungs-, Ausdrucks-, Seelenstreben-, Persönlichkeits- und
Reifezahl. Geburtsname und aktiver Name bleiben getrennt; Segmente und
Y-Klassifikationen sind auditierbar. Mehrdeutige Y-Fälle liefern beide Varianten.

Der neue Vertrag `profile-calculation-result-v1` besitzt einen eigenen
deterministischen Hash. Golden-, Property- und Vertragsprüfungen sichern alle
neuen Zahlen.
