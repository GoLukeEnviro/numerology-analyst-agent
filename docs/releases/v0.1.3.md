# v0.1.3 — Contract Integrity

- **Veröffentlicht:** 26. Juli 2026
- **Tag:** `v0.1.3`
- **Release-Commit:** `9c50f4d`
- **Implementierung:** PR #6
- **Release-Finalisierung:** PR #7
- **Kompatibilität:** Hashwerte aus `0.1.0`–`0.1.2` sind nicht mit `0.1.3` vergleichbar.

`v0.1.3` stärkt den deterministischen Berechnungsvertrag des Numerology Analyst Agent. Die numerologische Funktionalität bleibt auf Life Path A/B begrenzt; dieses Release korrigiert Vertrags-, Hash-, Schema- und Reproduzierbarkeitsprobleme.

## Highlights

- Vollständiger Calculation-Hash-Envelope statt Trace-only-Hash
- Explizite Schema-Version im Berechnungsergebnis
- Verpflichtendes `--as-of-date`
- Kanonische Behandlung von Dictionaries, Sets und Frozensets
- Versionierte JSON-Schemas im installierten Wheel
- Lockfile- und Schema-Drift-Gates in GitHub Actions
- Isolierter Package-Smoke-Test mit Python 3.12

## Breaking Changes

### `--as-of-date` ist verpflichtend

Vorher:

```bash
numerology profile --name "Max Mustermann" --birth 1985-07-25
```

Ab `0.1.3`:

```bash
numerology profile \
  --name "Max Mustermann" \
  --birth 1985-07-25 \
  --as-of-date 2026-07-26
```

### Hashsemantik geändert

Der Hash umfasst nun den fachlich relevanten Berechnungsvertrag:

- Schema-Version
- relevante Eingabedaten
- MethodPolicy
- Berechnungsergebnisse
- Audit-Trace

Hashwerte aus `0.1.0` bis `0.1.2` sind nicht mit Hashwerten aus `0.1.3` vergleichbar.
